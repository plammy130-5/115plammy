# 數位多媒體學生個人作品集網站

這是一個可供第1週課程展示與拆解的純 HTML、CSS、JavaScript 範例。

## 網站功能

- 首頁主視覺
- 個人介紹與技能標籤
- 作品展示區
- 作品分類篩選
- 深色／淺色主題切換
- 聯絡表單互動回饋
- 手機版響應式設計

## 教學拆解順序

1. `index.html`：觀察 `header`、`nav`、`main`、`section`、`article`、`footer`。
2. `styles.css`：觀察色彩變數、版面配置、作品視覺與手機版媒體查詢。
3. `script.js`：觀察主題切換、作品篩選、表單驗證與三大程式結構。

## 適合課堂展示的三個互動

- 選擇結構：作品分類與主題切換。
- 重複結構：`forEach` 逐一處理作品卡片。
- 順序結構：讀取設定、更新畫面、保存主題選擇。

## 注意

聯絡表單目前是前端展示，不會真的寄出電子郵件；之後可作為 API、後端或第三方表單服務的延伸教學案例。
